# 使用说明

## 翻译剪贴板

在 X11 或 Wayland 桌面中复制文字或图片，在该桌面的交互终端运行 `ts`。剪贴板同时提供受支持的图片和文字时，程序优先读取图片。剪贴板文字是已有图片文件的路径时，也会读取该图片。

## 其他输入

```bash
ts 'Hello world.'                   # 文字
ts ./screenshot.png                 # 已有图片路径
ts --text 'hello.png'               # 强制按文字处理
ts --image './screen shot.png'      # 强制按图片处理
printf 'Hello world.' | ts          # 标准输入文字
printf './screenshot.png' | ts      # 标准输入中的图片路径
```

输入优先级为显式参数、非终端标准输入、交互终端剪贴板。空输入报错，不回退到剪贴板。自动识别图片路径支持 PNG、JPEG、TIFF、BMP、WebP 和 GIF；多帧图片只处理第一帧。不要将图片二进制数据直接传入管道。

## 查看结果

支持排版的终端会显示原文和译文；原文超过一行时，两者之间有一个空行。等待时显示当前步骤。图片的原文来自同一次 OCR，不还原图片排版。

当 stdout 不是终端、使用 `--plain`、设置 `NO_COLOR` 或终端类型不受支持时，文字输入只输出译文；图片输入依次输出 OCR 原文和译文。只有标准输入来自管道并不会改变 stdout 的显示方式。

## 翻译规则与模型

程序识别中文和英文并译成另一种语言。中英混合文本分片翻译，因此结果可能仍包含两种语言。OCR 错字、短词、专业术语和上下文不足可能影响结果。

代码、明确命令、URL、路径和常见技术缩写会尽量保留。单独输入的 `grab_box` 会按英文词组翻译；要保留原样，请使用反引号。未知缩写和与中文相邻的路径可能有歧义，也可用反引号标明边界。

运行 `ts --models` 选择默认模式，运行 `ts --model plamo 'Hello world.'` 仅为本次选择 PLaMo。查看[模型选择](MODEL_SELECTION.md)和[命令参考](INTERFACE.md)了解完整选项。

安装时可选择 [Docker 常驻模式](INSTALLATION.md#可选docker-常驻模式)，以便跨命令复用语言识别器和模型；翻译命令、剪贴板及图片用法不变。
