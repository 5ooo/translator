# 使用说明

## 剪贴板

在 X11 或 Wayland 桌面中复制文字或图片，然后从交互终端运行 `ts`。工具会自动判断内容类型。图片先提取文字，再识别语言并翻译。

剪贴板同时提供图片和文字时优先使用图片。如果剪贴板文字是一个已存在的图片文件路径，也会识别图片。读取失败或剪贴板为空时，工具会显示错误。

## 其他输入

```bash
ts 'Hello world.'                      # 输入文字
ts --text 'hello.png'                  # 强制作为文字
ts --image './screen shot.png'         # 图片文件
printf 'Hello world.' | ts             # 管道文字
printf './screenshot.png' | ts        # 管道中的图片路径
```

单个位置参数指向已存在的图片文件时，也可以省略 `--image`。支持 PNG、JPEG、TIFF、BMP、WebP 和 GIF；多帧图片只处理第一帧。不要把图片二进制直接传入管道。

输入优先级为显式参数、管道输入、交互终端剪贴板。空的显式输入或空管道会报错，不会转而读取剪贴板。

## 结果显示

在支持颜色的交互终端中，文字和图片都显示原文及译文。原文标签和正文使用相同的淡色；原文折行或包含换行时，译文前增加一个空行。等待时显示当前处理步骤，完成或出错后清除。

使用 `--plain`、重定向输出，或者设置 `NO_COLOR` 时，普通文字只输出译文；图片依次输出 OCR 原文和译文。OCR 原文保留识别结果中的空白和换行。`TERM=dumb` 或无法识别的终端也使用纯文本输出。

## 翻译和保留规则

工具识别中文和英文，分别译成另一种语言。中英混合内容会分片处理，因此结果也可能包含中英文。OCR 错字、短词、专业术语和缺少上下文都可能影响译文。

代码围栏、行内代码、明确的命令、URL、路径和常见技术缩写会按规则保留。例如：

```bash
ts '请检查 API 和 GPU 状态。'
ts '请打开 `./report.txt` 后重试。'
```

单独输入的 `grab_box` 会按英文词组翻译；要原样保留，可使用反引号包围。未知缩写和中文紧邻的裸路径可能存在歧义，需要保留时建议使用反引号。更完整的规则见[需求规格](需求规格.md)。

## 模型与自检

使用 `ts --models` 查看模型，使用 `ts --set-model plamo` 或 `ts --set-model argos` 切换默认模型。`ts --model plamo 'Hello world.'` 只影响本次命令。

`ts --check` 检查默认模型和公共依赖；`ts --check --model argos` 检查指定模型。模型安装及配置见[模型选择](模型选择.md)。
