# 接口说明

本程序提供一次性终端命令，不提供对外 HTTP 服务。使用示例见[使用说明](使用说明.md)；内部流程见[架构设计](架构设计.md)。

## 命令与输入

| 接口 | 作用 |
| --- | --- |
| `ts` | stdin 为交互终端时读取剪贴板中的文字或图片 |
| `ts '文字'` | 翻译文字；单个参数为已有图片路径时识别图片 |
| `ts --text '文字'` | 强制按文字处理 |
| `ts --image 图片路径` | 强制按图片文件处理 |
| `命令 \| ts` | 读取 UTF-8 管道文字，也接受单个已有图片路径 |
| `ts --models` | 显示模式，用 `*` 标记当前选择，不可用时提示 |
| `ts --model 名称` | 仅本次使用 `argos` 或 `plamo`，可与文字或图片输入组合 |
| `ts --set-model 名称` | 检查模型可用后保存默认选择 |
| `ts --check [--model 名称]` | 检查所选模型和公共依赖 |
| `ts --install-model 文件.argosmodel` | 导入一个本地 Argos 模型包 |
| `ts --plain ...` | 以纯文本输出，不显示动画和颜色 |

有显式参数时优先使用显式输入；否则有管道时读取 stdin，交互终端下才读取剪贴板。空参数和空管道报错，不回退到剪贴板。支持 PNG、JPEG、TIFF、BMP、WebP 和 GIF；多帧图片仅处理第一帧。

管理命令不读取剪贴板。`--set-model` 检查模型后以临时文件替换配置，并保留其他 JSON 字段。模型不可用或配置损坏时不会静默换用其他模型。

## 输出与退出码

支持排版的交互终端显示原文与译文；原文折行时在译文前增加空行。普通文字经管道或 `--plain` 输出时，stdout 只包含译文；图片还包含 OCR 原文。错误写到 stderr，不输出部分译文。

| 退出码 | 含义 |
| --- | --- |
| `0` | 成功 |
| `1` | 输入、模型或依赖错误 |
| `2` | 命令参数错误 |
| `130` | 用户中断 |

## 文件与环境边界

模型、配置及缓存默认位于项目 `.runtime/`；`XDG_DATA_HOME`、`XDG_CONFIG_HOME`、`XDG_CACHE_HOME` 和 `ARGOS_PACKAGES_DIR` 可覆盖对应目录。`XDG_CONFIG_HOME` 必须是绝对路径。`TS_PLAMO_MODEL`、`TS_PLAMO_RUNNER` 和 `TS_PLAMO_DEVICE` 可指定 PLaMo 模型、运行器和设备模式。详细位置与安装方法见[安装与配置](安装与配置.md)和[模型选择](模型选择.md)。

PLaMo 运行器由本程序按需启动，只监听本机回环地址，端口由系统分配；程序验证连接归属于该子进程后才发送内容。运行结束或出错时关闭该进程。翻译和 OCR 不请求外部网络。

剪贴板工具的单次调用超时为 5 秒，OCR 超时为 120 秒。PLaMo 单次运行器启动等待最多 45 秒，单次响应等待最多 120 秒；自动设备模式下，显卡运行器启动失败会尝试 CPU。超时和模型失败会报告错误。
