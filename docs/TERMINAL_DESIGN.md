# 终端显示

## 交互输出

支持排版的终端中，文字和图片均显示 `原文：内容` 和 `译文：内容`。原文标签与正文使用相同的淡色，译文正文使用终端默认颜色。原文因自身换行或终端宽度显示为多行时，译文前增加一个空行。

内容作为字面文本输出，保留内部换行；Rich 不把输入中的标记当作样式。等待时显示输入、剪贴板、OCR、语言识别、模型载入或翻译等实际阶段，结束、出错或中断时清除动画。

## 纯文本输出

当 stdout 不是终端、设置了 `NO_COLOR`、指定 `--plain`，或 `TERM` 为空、`dumb`、`unknown` 时，不启用排版。动画还要求 stderr 是终端。stdin 是否为终端只影响默认输入来源。

普通文字只输出译文；图片输出 OCR 原文和译文。OCR 原文保留已有空白和换行。详细规则见[命令参考](INTERFACE.md)。
