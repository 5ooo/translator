## 实用边界

验收证明当前机器的完整流程和独立桌面协议可用，不保证机器翻译具有人工作者的准确度。OCR 错字、极短文本、专业词和缺少上下文仍可能影响译文。同一混合输入中的自然语言全部分别互译，因此结果可以继续包含中英文。

专业缩写采用明确词表与技术形态保护，未知纯字母缩写可能翻译，必须保留时使用行内代码。裸 Unicode 路径与相邻中文无法总是准确区分，路径两侧留空格或使用反引号。特别是 `检查/tmp/a.py` 可能被视为完整相对路径；建议写成 `检查 /tmp/a.py` 或为路径加反引号。图片输出为纯文字译文，不重建图片版式。

不同机器或 Python 版本需重新验收依赖与桌面环境。当前 Codex 会话未连接用户日常桌面，剪贴板协议已在独立 X11 和 Wayland 会话实测。
