# 需求与功能边界

ts 是 Linux 离线终端中英翻译工具。部署可联网获取依赖和模型；识别、OCR 和翻译在本机运行，不下载模型或调用在线翻译。完整命令见[命令参考](INTERFACE.md)。

## 输入

- 输入优先级为显式参数、非终端 stdin、交互终端剪贴板；空输入报错。
- 文字与图片路径可来自参数、stdin 或剪贴板。`--text` 和 `--image` 可强制指定类型。图片通过 Tesseract `eng+chi_sim` 识别，再进入文字处理流程。
- X11 使用 `xclip`，Wayland 使用 `wl-paste`；同时存在时先尝试 Wayland。剪贴板优先读取受支持的图片 MIME，再读取 UTF-8 文字。
- 自动识别 PNG、JPEG、TIFF、BMP、WebP 和 GIF 路径；多帧图片只处理第一帧。程序不执行输入中的命令，也不修改剪贴板。

## 识别与翻译

自然语言片段使用本地 langid，在中文和英文之间判断方向；数字、标点及受保护片段不送入语言识别或翻译模型。自然语言按换行分块，中英混合文本再按文字系统分片，较长片段限制为最多 400 字符。程序不按句点强制分句。

围栏代码、缩进或行内代码、明确命令、URL、路径、常见缩写和部分标识符按规则保留。独立的 `grab_box` 一类小写下划线词组会转为空格后翻译；反引号可要求原样保留。未知缩写及与正文相邻的路径存在歧义，不保证全部判断正确。

## 模型与结果

仅提供本地 Argos 和 PLaMo 两种模式，分别面向速度和效果。`ts --models` 保存选择，`--model` 临时覆盖；模型不可用时明确报错，不自动换用其他模型。

支持排版的终端显示原文、译文和真实处理阶段；原文显示为多行时，在译文前加入空行。纯文本模式下，文字只输出译文，图片先输出同一次 OCR 的原文再输出译文。翻译失败时不输出部分结果。

模型、路径和显示的实现细节见[架构设计](ARCHITECTURE.md)；测试要求见[实现与验证](IMPLEMENTATION.md)。
