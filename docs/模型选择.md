# 模型选择

工具只提供 `argos` 和 `plamo` 两种本地翻译模型。两者都支持中英双向翻译，并共用文字识别、OCR、输入优先级、技术片段保护和终端显示。

## 切换模型

```bash
ts --models                           # 查看两种模型的可用状态和默认值
ts --model plamo                      # 本次用 PLaMo 翻译剪贴板
ts --model argos --text 'Hello world.'  # 本次用 Argos 翻译文字
ts --set-model plamo                  # 将 PLaMo 设置为默认
ts                                    # 用默认模型翻译剪贴板
ts --set-model argos                  # 切回 Argos
ts --check --model plamo              # 检查 PLaMo 和公共依赖
```

如果模型显示“不可用”，可用 `ts --check --model 模型名` 查看原因。

`--model` 只影响当前命令。没有保存设置时默认使用 `argos`；`--set-model` 保存后，直接运行 `ts` 使用所选模型。运行 `ts --models` 可查看当前默认模型。保存前会检查模型是否可用，指定模型缺失或配置损坏时明确报错，不会静默切换；配置损坏时仍可通过 `--model argos` 临时指定模型。若旧配置选择的是已移除的模型，可运行 `ts --set-model argos` 或 `ts --set-model plamo` 重新设置。

设置只在运行 `--set-model` 后写入 `$XDG_CONFIG_HOME/ts/config.json`，采用临时文件加原子替换，并保留其他 JSON 项。通过项目 `bin/ts` 调用且未设置 `XDG_CONFIG_HOME` 时，配置位于项目 `.runtime/config/ts/config.json`。模型管理命令不读取剪贴板或管道输入。

## Argos

`argos` 使用两个本地 `.argosmodel` 方向包，由项目安装脚本安装。已有模型包时，可用 `ts --install-model 文件.argosmodel` 离线导入。翻译使用本地 CTranslate2 推理，不调用远程服务。

## PLaMo

`plamo` 使用 PLaMo 3 Translate 0.8B Q4_K_M，模型文件约 573 MB。项目目录中运行 `.venv-uv/bin/python scripts/install-plamo.py`，可下载并校验固定版本的模型和 Linux x86-64 CPU 运行器；添加 `--vulkan` 可安装 Vulkan 显卡运行器。已有文件时，可用 `--model-file`、`--runtime-archive` 和 `--vulkan-archive` 离线安装。模型默认位于项目 `.runtime/data/ts/models/plamo3/`；设置 `XDG_DATA_HOME` 时改用该目录下的 `ts/models/plamo3/`，也可通过 `TS_PLAMO_MODEL` 指定本地 GGUF 文件；运行器默认放在项目 `.runtime/tools/`，也可通过 `TS_PLAMO_RUNNER` 指定兼容的 `llama-server`。

当前模型固定为[官方 Q4_K_M 文件](https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF/tree/1cf96ae02133958a20074bfdfab76517bb737d00)，SHA256 为 `70891ec70dc7ab4205745a38307867c2881b99239f20327927633abfe4bc9ec6`。

安装 CPU 运行器和模型：

```bash
.venv-uv/bin/python scripts/install-plamo.py
ts --check --model plamo
```

如需同时安装 Vulkan 显卡运行器，在安装命令后加 `--vulkan`。已有模型文件和官方运行器压缩包时，可离线安装：

```bash
.venv-uv/bin/python scripts/install-plamo.py --model-file ./plamo.gguf --runtime-archive ./llama-b12110-bin-ubuntu-x64.tar.gz
```

如需离线安装 Vulkan 运行器，再指定 `--vulkan-archive` 和对应压缩包。安装脚本验证 SHA256，不覆盖现有的不同文件，重复运行会复用完整安装。模型文件约 573 MB，运行器和 Python 依赖另占空间。

默认优先尝试已安装的 Vulkan 运行器，启动失败时回退 CPU；设置 `TS_PLAMO_DEVICE=cpu` 可只用 CPU。该后端使用私有本地进程和经验证的回环连接，翻译时不联网、不自动下载模型；进程随命令结束而退出。模型、运行器和 Python 环境不包含在 Git 提交中。[PLaMo Community License](https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF) 对个人和非商业用途免费；商业使用有条件，使用前请核对许可。模型来源及其他许可说明见[第三方许可](第三方许可.md)。

每次命令都会初始化语言识别；PLaMo 还需要启动运行器并加载模型，因此短句可能比 Argos 慢。可用 `ts --model argos` 临时使用 Argos，不改变默认配置。

模型效果随内容而异，应使用自己的中英短句、混合文字和专业词比较；长内容或模型错误会报告失败，不会静默输出截断的结果。交互终端显示原文和译文；重定向或 `--plain` 保持纯文本格式。
