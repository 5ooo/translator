# 第三方许可和模型来源

本文记录当前已核实的主要来源，不是完整依赖许可证清单。项目自身尚无 `LICENSE` 文件；公开发布前需要由项目负责人确定许可，并检查实际分发内容及其许可要求。

## Argos

当前 Python 依赖为 Argos Translate 1.9.6。其[程序许可证](https://raw.githubusercontent.com/argosopentech/argos-translate/v1.9.6/LICENSE)为 MIT；分发其代码时须保留相关版权和许可声明。

当前中英双向模型包名及下载地址、SHA256 见 `scripts/models.json`。两个包各自的 README 均说明它们来自 OPUS 模型，原始模型采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)；包内列出的作者为 Jörg Tiedemann 和 Santhosh Thottingal。CC BY 4.0 包含署名、许可链接和修改说明等要求。

上述说明明确的是原始 OPUS 模型的许可，不能据此确认 Argos 打包文件中每个组成部分的完整许可。若直接随软件分发模型包或权重，需要进一步确认转换模型和其他包含文件的授权。

## PLaMo

当前使用 [PLaMo 3 Translate 0.8B Q4_K_M](https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF)，使用 PLaMo Community License。官方模型页说明个人及其他非商业使用免费；商业使用存在注册或单独许可条件。请以模型页链接的许可文本和实际用途为准。

模型及运行器的固定版本、下载地址和 SHA256 记录在 `scripts/install-plamo.py`。模型和运行器默认放在 `.runtime/`，不随 Git 源码提交。

## 其他依赖

CTranslate2、SentencePiece、Tesseract、llama.cpp、langid、Pillow、Rich、PyTorch 和其他传递依赖各自具有许可证。分发 Python 环境、运行器、OCR 资源或生成的安装包时，需要按照实际打包内容检查并保留适用的许可和署名文件；本页不代表已完成全部许可证审计。
