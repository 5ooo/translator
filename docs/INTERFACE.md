# 命令参考

使用示例见[使用说明](USAGE.md)。

| 命令或参数 | 作用 |
| --- | --- |
| `ts [文字或图片路径]` | 翻译参数；无参数时读取标准输入或剪贴板 |
| `--text 文字` | 强制按文字处理，即使内容是图片路径 |
| `--image 路径` | 强制读取图片并执行 OCR |
| `--models` | 交互选择模式；非交互时只显示模式列表 |
| `--model argos\|plamo` | 只为本次翻译或自检选择模型 |
| `--check` | 检查当前或指定模型、OCR 和公共依赖 |
| `--plain` | 纯文本输出，不显示颜色和动画 |
| `--help` | 显示命令帮助 |

`--text`、`--image`、`--models` 和 `--check` 互斥，也不能与位置参数混用。`--model` 不能与 `--models` 混用。

## 输入与输出

程序依次选择显式输入、非终端 stdin 和交互终端剪贴板。剪贴板优先读取支持的图片，再读取文字。参数、标准输入和剪贴板文字中的单个已有图片路径会触发 OCR。

支持排版的 stdout 显示原文和译文。纯文本模式下，文字只输出译文；图片依次输出 OCR 原文和译文。输入和翻译错误写入 stderr，失败时不输出部分译文；`--check` 的检查结果写入 stdout。状态动画还要求 stderr 是终端。

| 退出码 | 含义 |
| --- | --- |
| `0` | 成功 |
| `1` | 输入、依赖或模型错误 |
| `2` | 参数用法错误 |
| `130` | 用户中断 |

`--check` 报告两个剪贴板工具是否存在，但仅缺少其中的工具不会使自检失败；对应桌面环境仍需安装相应工具。启用 Docker 常驻模式时，自检也会检查常驻服务连接。自检不替代实际翻译或 OCR 测试。

剪贴板工具单次调用超时为 5 秒，OCR 为 120 秒。PLaMo 运行器启动等待最多 45 秒，单次推理响应等待最多 120 秒。文件位置与环境变量见[安装与配置](INSTALLATION.md)和[模型选择](MODEL_SELECTION.md)。
